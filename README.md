# API Tasks - Node.js + Express

API REST simples desenvolvida para estudo de Node.js, Express e integração com banco NoSQL (Firebase).

## Tecnologias
- Node.js
- Express
- Firebase (Firestore)
- Git e GitHub

## Objetivo
Projeto educacional para entender:
- Criação de APIs REST
- Rotas e controllers
- Integração com banco de dados
- Versionamento de código
